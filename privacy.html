Datenschutzerklärung – Sensor Widgets

Stand: 4. November 2026
Verantwortlich: Manuel Gaschler, prompt-engineered@protonmail.com

Sensor Widgets ist eine quelloffene App, mit der du Widgets für den Startbildschirm einrichtest, die Messwerte aus einer InfluxDB-Datenbank anzeigen.

Keine Datenerhebung durch den Entwickler

Die App hat keinen eigenen Server, kein Benutzerkonto, keine Werbung, keine Analyse- oder Absturzberichts-Dienste und kein Tracking. Der Entwickler erhält keinerlei Daten von dir oder deinem Gerät.

Was auf deinem Gerät gespeichert wird

Die von dir eingegebenen Verbindungsdaten (Name, Server-Adresse, Datenbank/Bucket, optional Organisation) und Widget-Einstellungen werden lokal auf dem Gerät gespeichert. API-Tokens werden verschlüsselt im sicheren Speicher des Betriebssystems abgelegt (Android Keystore). Zuletzt abgerufene Messwerte werden lokal zwischengespeichert, damit Widgets auch ohne Netz etwas anzeigen. Alle Daten werden gelöscht, wenn du die App deinstallierst oder ihre Daten löschst.

Netzwerkverbindungen

Die App und ihre Widgets verbinden sich ausschließlich mit der Datenbank-Adresse, die du selbst einträgst, um dort Daten zu lesen. Dabei wird dein API-Token zur Anmeldung an diesen Server übertragen. Für die Verarbeitung auf diesem Server ist dessen Betreiber verantwortlich (z. B. du selbst oder InfluxData bei InfluxDB Cloud). Verwende nach Möglichkeit eine HTTPS-Adresse.

Teilen

Wenn du die Funktion „Widget als Code“ teilst, wird die Widget-Konfiguration über das Android-Teilen-Menü an die von dir gewählte App übergeben. Verbindungsdaten und API-Tokens sind darin nicht enthalten.

Berechtigungen

  • Internet: Abruf der Messwerte von deinem Server.
  • Benachrichtigungen (optional): lokale Hinweise, wenn ein Messwert eine von dir festgelegte Schwelle überschreitet.

Kinder

Die App richtet sich nicht an Kinder.

Änderungen

Diese Erklärung kann mit neuen Versionen angepasst werden; die aktuelle Fassung steht unter dieser Adresse.

Privacy Policy – Sensor Widgets

Last updated: November 4, 2026
Controller: Manuel Gaschler, prompt-engineered@protonmail.com

Sensor Widgets is an open-source app for setting up home-screen widgets that show readings from an InfluxDB database.

No data collection by the developer

The app has no backend, no user account, no ads, no analytics or crash-reporting services and no tracking. The developer receives no data from you or your device.

What is stored on your device

The connection details you enter (name, server URL, database/bucket, optional organization) and widget settings are stored locally on the device. API tokens are stored encrypted in the operating system's secure storage (Android Keystore). The latest readings are cached locally so widgets can show data while offline. All data is removed when you uninstall the app or clear its data.

Network connections

The app and its widgets connect only to the database URL you enter, to read data from it. Your API token is sent to that server to authenticate. The operator of that server (e.g. you, or InfluxData for InfluxDB Cloud) is responsible for processing there. Use an HTTPS URL where possible.

Sharing

When you share a widget as code, the widget configuration is passed to the app you choose via the Android share sheet. Connection details and API tokens are not included.

Permissions

  • Internet: fetching readings from your server.
  • Notifications (optional): local alerts when a reading crosses a threshold you set.

Children

The app is not directed at children.

Changes

This policy may be updated with new versions; the current version is published at this address.
